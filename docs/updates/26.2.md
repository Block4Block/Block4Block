# Minecraft 26.1.2 → 26.2

The third step towards 26.3, one version at a time (Server Queue SQ2 and SQ45). Started 27 November 2026, right after
26.1.2 went live (SQ56). Paper 26.2 build 135 (stable).

## What 26.2 adds
Found by comparing the Paper API's block, item and mob lists for 26.1.2 and 26.2, then reading minecraft.wiki:
- **Sulfur caves**, a cave biome (also open to the surface as sulfur springs), with:
  - two stone families, **sulfur** and **cinnabar**, each with slab, stairs, wall, polished, bricks and chiseled
    forms (26 blocks; pickaxe needed, like stone);
  - **sulfur spike**: hangs and stands like pointed dripstone, grows under sulfur, falls and hurts; four craft into one
    sulfur; wandering traders sometimes sell them;
  - **potent sulfur**: crafted from nine sulfur; with water on top it gives off nausea gas, and on magma it is a
    geyser that launches entities up to 20 blocks. Pistons can't move it.
- **Sulfur Cube**, one new mob: spawns only in sulfur caves, hops, fights only when provoked; hand it a block and it
  takes on that block's bounce (TNT makes it explode); large ones can be bucketed; it drops the block it holds.
- **Music disc "Bounce"**, from mineshaft chests in sulfur caves.
- Data format 107.1; protocol 776; Java 25 (as 26.1).
- Nothing removed from the API (only two `package-info` classes).

## Other ways to break the new blocks (tested on the copy, for the owner's choices)
Block4Block charges for blocks a player breaks, and decides what TNT-broken blocks drop; every other way of breaking
follows vanilla. Tested with `indirect.py` on the 26.2 copy, reading drops from the server:
- **Sulfur spike** drops itself, free, when hit by a thrown trident, when a piston pushes a block into it, and when the
  block it hangs from or stands on is removed. Arrows, water and lava don't break it; sand landing on it pops into an
  item (as on a slab). The same as pointed dripstone.
- **Sulfur, cinnabar and their forms**: pistons move them without breaking; water and lava leave them; TNT drops
  nothing; creepers drop some (as for every block).
- **Potent sulfur**: pistons can't move it; water doesn't break it; TNT drops nothing; creepers drop it.

## Changes
### Block4Block 4.14 (branch `update/26.2`)
- Built against the Paper 26.2 API (build 135) with JDK 25.
- Sulfur Cube spawn egg at weight 15, like the slime (SQ60), before the black bear entry.
- In `no-loot-on-break` (cost one, drop nothing): sulfur and all its forms, like tuff (SQ58: spikes craft into sulfur, so
  it stays obtainable); potent sulfur, like the magma block (SQ59); the sulfur spike, like pointed dripstone (SQ61);
  cinnabar's crafted forms, like tuff's. Natural cinnabar can't be crafted or grown, so how players get it is SQ64.

### Essential datapack (branch `update/26.2`)
- `pack.mcmeta` supports data format up to 107.
- **`overlay_107`**: 26.2 renamed two entity-predicate fields in loot tables: `type` is now `minecraft:entity_type`,
  and `type_specific: {type: K, …}` is now `minecraft:type_specific/K` (slime and magma cube: `cube_mob`; also the
  fishing hook). Without this, nine loot tables failed to load on 26.2: fishing, the sheep heads, creeper, ghast, magma
  cube, pillager, sheep, slime, zombie. The overlay holds converted copies of exactly those nine (made by
  `overlay107.py`, which converts the file each format actually uses). Older versions keep their files.
- **`overlay_94`, a fix for today's server too**: since 1.21.11 (data format 94) bees and wolves store anger as
  `anger_end_time`, not `AngerTime`, so the calm bee and wolf heads never matched, and every bee and wolf has dropped
  the angry head since the 1.21.11 update. Now the calm head drops for a bee or wolf that was never angry
  (`anger_end_time:-1L`); one that was angry and calmed down keeps its old anger time and still drops the angry head.
  The owner decides whether it goes live now (SQ62).
