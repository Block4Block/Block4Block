# Minecraft 1.21.10 → 1.21.11

The first step towards 26.3, one version at a time (Server Queue SQ2 and SQ45). Started 26 November 2026.

## What 1.21.11 adds
- **No new blocks** and none removed, so no new break types to decide.
- New items: spears (wooden to netherite), netherite horse armor and nautilus armor (copper to netherite).
- New mobs: nautilus, zombie nautilus, camel husk, parched. Their spawn eggs are new items too.

## Changes
### Block4Block (branch `update/1.21.11`)
- **Built against the 1.21.11 Paper API** (`pom.xml`; it was 1.21.7).
- **Skins for disguises.** Block4Block saves each player's skin when they join, and swaps skins when a player puts on
  another player's head (the disguise). It read and wrote skins through Minecraft's internal `GameProfile`, which recent
  Paper builds made read-only (already 1.21.10 build 130, so the live server has this bug too): every join failed with `NoSuchMethodError: GameProfile.getProperties()`, so no skin was saved. It now
  uses Paper's public `PlayerProfile` interface, which works the same on 1.21.10 and 1.21.11. Nothing else in the disguise
  changed: the same 5-second duration, the same claim-membership rule, the same saved-skin file.
- **Master Book copies on lecterns** (a bug already on the live 1.21.10, found while testing): reading a lectern whose
  copy was out of date threw in ProtocolLib, because the block entity packet it built lost a field in 1.18, so the
  lectern never opened; and the stale block state wrote the old book back over the new one. The book is now written
  through the lectern's snapshot and the lectern opened normally, which shows the new pages. Block4Block no longer sends
  any ProtocolLib packet.
- **Claim bar during the claim questline** (the owner, in chat, 26 November). The claim bar stays hidden until a player
  finishes the claim questline, so new players couldn't tell they were standing in someone's claim (the owner met
  "This chunk is already claimed!" without warning). Now, before the questline is done, the claim bar shows whenever
  the player stands on claimed land, and still hides on unclaimed land. The claim bar is always the top bar and the
  quest bar sits under it (the owner's choice): showing a boss bar again puts it at the bottom, so the quest bar is
  re-added under it each time. The bar still updates when a player crosses a chunk border, as before.
  `claimbarbot.js` checks it: 6 of 6.
- **Spawn eggs** (SQ46, the owner's weights): nautilus 50, zombie nautilus 10, camel husk 10, parched 10, placed before
  the black bear entry. Only for 1.21.11: these eggs don't exist on 1.21.10.
- **Test bots:** `tooltipbot.js` takes the recipes away before giving them, so its recipe book check also works for a
  player who already knows them; `disguisebot.js`, `lecternbot.js` and `pluginsbot.js` are new. All take `B4B_PORT` and `B4B_VERSION`.

### Essential datapack (branch `update/1.21.11`)
- `pack.mcmeta` declares support up to data format 94, 1.21.11's. Nothing else changed: the datapack loaded on 1.21.11
  with no errors before this, and the format number only stops it being listed as made for an older version.
